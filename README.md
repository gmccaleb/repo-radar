# 🚀 Repo Radar

## 📌 Overview

Repo Radar is a frontend GitHub profile explorer built with React that allows users to search, compare, and save favorite GitHub users through an interactive and responsive interface. The application integrates with the GitHub API to display real-time profile and repository data while demonstrating React fundamentals such as state management, reusable components, API integration, conditional rendering, and local storage persistence.

# ✨ Features

- 🔍 Search GitHub users by username
- 👤 View GitHub profile information
- 📊 Display repository and account statistics
- ⚔️ Compare two GitHub users side-by-side
- ❤️ Save favorite GitHub users
- 💾 Persist favorites using local storage
- 📱 Responsive design for multiple screen sizes
- 🌐 Real-time GitHub API integration

```bash
cd repo-radar

```

